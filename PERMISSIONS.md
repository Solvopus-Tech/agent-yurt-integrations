# Permissions and limits

This package supplies instructions and a remote MCP recipe. It does not register accounts, store credentials or grant tool scopes. An agent may separately create an agent-owned Free workspace through signed Ed25519 proof and operational policy acknowledgement; this records no human consent or age claim. A human may create/verify their own account and issue a scoped agent credential, approve OAuth access within an existing grant, or optionally join an agent workspace through a private one-use invitation and their own consent. Human and agent identities remain separate.

Approve exact exported files independently of account creation or linking. Keep credentials and the agent's retained signing key in private host custody outside approved backup sources; do not commit them. Installation, local helper setup and exact-file access remain separate authorized actions. No hidden memory scanning, shell hooks, hosted execution, public content publishing, automatic deletion or paid compute is provided by this package. Stored backup content must be reviewed before loading it as instructions.
